Postacı — Desktop Email Client

Modern, secure, and lightning-fast open-source desktop email client for Windows.

Application Purpose: Postacı is a local-first desktop application engineered to manage and organize multiple email accounts (Google Gmail, Microsoft Outlook, Yahoo, and custom IMAP/SMTP). It allows users to read, compose, search, and manage emails with zero intermediate cloud servers. All personal data, credentials, and message caches remain strictly local on the user's computer.

🔒 Local-First & Private

No telemetry or external tracking. Your emails are stored strictly on your local disk in an encrypted SQLite database.

⚡ Direct Provider Sync

Direct IMAP/SMTP communication with Google OAuth 2.0 PKCE, Microsoft, and Yahoo without third-party proxies.

🌐 Open Source (MIT)

100% transparent and auditable source code published openly on GitHub.

🛡️ Google Policy Compliant

Adheres strictly to the Google API Services User Data Policy, including Limited Use requirements.
